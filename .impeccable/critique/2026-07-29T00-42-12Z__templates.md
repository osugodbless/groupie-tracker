## Priority Issues

### P0 — No search or filter
52+ artists in a flat grid, only discoverable by scrolling. Fix: HTMX search bar with server-side `?q=` filter.

### P0 — HTMX breaks URL state
No `hx-push-url`, no `document.title` updates. Browser Back unpredictable. Fix: add `hx-push-url="true"` and `hx-on::after-request` for title updates.

### P1 — Silent image 404 with no fallback
`onerror="this.style.display='none'"` creates blank holes. Fix: swap to inline SVG placeholder on error.

### P1 — No scroll persistence or visited state
HTMX replaces `#index`, resetting scroll. Fix: `sessionStorage` scroll restore + visited opacity class on cards.

### P2 — Artist context missing from tour dates
"Concert Dates & Locations" heading lacks artist reference. Fix: add artist name + thumbnail to tour page heading.

### P2 — No empty states for sub-sections
Zero members, zero dates produce broken-looking sections. Fix: `{{ else }}` blocks with clear messages.

### P3 — Redundant hover overlay on cards
Overlay duplicates always-visible name + year. Fix: remove overlay or show different info.
